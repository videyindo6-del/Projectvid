PERBAIKAN REVIEW / DOWNLOAD / PASTE BOXCELLINK

Akar masalah yang diperbaiki:
1. Aturan _redirects sebelumnya menambahkan query parameter dinamis pada rewrite. Versi ini menggunakan proxy rewrite path-only yang didukung Cloudflare Pages.
2. Browser mempertahankan URL /r/KODE, /d/KODE, dan /paste/KODE. JavaScript mengambil kode dari segmen terakhir URL, bukan bergantung pada query string.
3. Halaman review tidak lagi gagal total jika kolom tambahan gallery_urls/view_count atau RPC penghitung view belum ada.
4. Query publik hanya mengambil metadata review; tabel link download dan konten privat tetap tertutup.

LANGKAH PEMASANGAN
1. Ekstrak ZIP ini.
2. Upload/Deploy SELURUH isi folder hasil ekstrak ke root project Cloudflare Pages (bukan folder pembungkus ZIP).
3. Pastikan file _redirects berada di root output yang benar dan isinya berasal dari ZIP ini.
4. Buka Supabase Dashboard > SQL Editor, pilih project yang sama dengan website, lalu jalankan isi supabase/review_public_access_fix.sql.
5. Tunggu deployment Cloudflare selesai. Lakukan hard refresh atau buka lewat mode privat.

CATATAN AKSES
- /r/KODE menampilkan detail review yang published.
- /d/KODE menampilkan checkout. Konten paid memerlukan login dan pembayaran.

Jika masih gagal setelah deployment, kirim screenshot hasil halaman dan error dari browser Console/Network serta hasil SQL verifikasi di atas. Jangan kirim service-role key.
